# Recipes

Copy what you need.

| Folder / file | What |
|---|---|
| `agents/` | Agent file templates: `researcher`, `critic`, `reviewer`, `builder`, `qa`. Copy into `.claude/agents/`, edit the brief for your project. |
| `hooks/` | A guard hook with a rules file, a session-start hook, a sub-agent spawn log. Install instructions in `hooks/README.md`. |
| `CLAUDE.template.md` | A short project instruction file with a "never break" list, plus an example of a path-scoped rules file. |
| `retro_template.md` | Blameless retro: timeline, 5 whys, proposed rules with an owner and a check. |

The thinking behind them: [docs/HOWTO_RUN_AN_AI_AGENT_TEAM.md](../docs/HOWTO_RUN_AN_AI_AGENT_TEAM.md).
